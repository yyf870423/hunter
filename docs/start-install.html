安装与启动

试用期间我们为每位用户单独打包，安装包直接发给你，无需自行下载。 整个过程很简单：解压 → 双击启动 → 浏览器打开，三步就能用。

你收到的是什么

你拿到的是一个 .zip 压缩包（文件名形如 HunterTrial-XXX-版本号-win-x64.zip，其中 XXX 是你的名字）。 里面打包了 Hunter 运行需要的全部东西——程序本体、内置浏览器、以及你的专属配置， 解压即用，不需要再装任何别的软件。

目前是 Windows 版（64 位）

试用包是为 Windows 64 位系统打的。 包比较大（约 400 MB，含内置浏览器），下载/拷贝时请耐心等传完整。

第 1 步：解压

  1. 把 .zip 放到一个固定的位置

    建议放在一个路径短、以后不会随便挪动的地方，比如 D:\Hunter\ 或桌面。 不建议放在「下载」文件夹里——那里容易被你顺手清空。

  2. 右键 → 全部解压缩

    解压会得到一个文件夹（名字和压缩包一样）。 里面有 HunterStart.exe 等几个程序和 bin/、browsers/ 等文件夹。

要改文件夹名字？请在「第一次启动之前」改

如果你想给解压出来的文件夹重命名（比如改成 Hunter）， 一定要在第一次启动之前改好。 一旦启动过，程序会记住自己所在的位置，事后再改名字或挪动文件夹可能导致启动异常。 记住一个原则：名字和位置先定好，再双击启动。

第 2 步：启动

进入解压后的文件夹，你会看到三个绿色的启动程序：

启动

HunterStart.exe

双击它启动 Hunter。第一次启动会稍慢，请耐心等几十秒。

停止

HunterStop.exe

双击它关闭 Hunter。用完不想让它在后台跑时用。

重启

HunterRestart.exe

双击它重启 Hunter。遇到卡住或异常时，重启往往能解决。

  1. 双击 HunterStart.exe

    会弹出一个黑色的命令行窗口，显示启动进度。 这个窗口不要关——它就是 Hunter 的运行窗口，关掉它 Hunter 就停了。 把它最小化放着即可。

  2. 等到提示启动完成

    第一次启动需要初始化，可能要等几十秒到一两分钟，之后再启动就快了。

第 3 步：打开浏览器访问

  1. 打开浏览器（推荐 Chrome / Edge）
  2. 地址栏输入 127.0.0.1:8000 回车

    这就是 Hunter 的本机访问地址。看到工作台界面就说明启动成功了。 建议把它加到书签，以后直接点开。

所有数据都在你自己电脑上

127.0.0.1 是「本机」的意思——Hunter 跑在你自己的电脑里， 候选人、岗位、客户信息全部存在本地，不上云。这正是 Hunter 的核心： 下班关机就是关门，数据不出本机。

启动成功后，接着看「10 分钟上手」跑通第一遍完整流程。

日常：停止与重启

  • 不用了想关掉：双击 HunterStop.exe（或直接关掉那个黑色命令行窗口）
  • 遇到卡顿 / 异常：双击 HunterRestart.exe，等它重启完再刷新浏览器
  • 下次再用：重新双击 HunterStart.exe，数据都还在
遇到问题先「重启」试试

绝大多数小问题（页面打不开、操作没反应、上传卡住）—— 先双击 HunterRestart.exe 重启一次，再刷新浏览器，往往就好了。 这是最省事的第一招。

进阶：命令行启动（可选）

如果你习惯用命令行，也可以在解压后的文件夹里用 bin/hunterctl 操作：

  • bin/hunterctl start — 启动
  • bin/hunterctl stop — 停止
  • bin/hunterctl restart — 重启
  • bin/hunterctl status — 查看当前运行状态
  • bin/hunterctl logs — 查看运行日志（排查问题时有用）

不用命令行也完全没关系——双击那三个 .exe 就够日常使用了。

你的数据存在哪

Hunter 的所有数据都保存在解压文件夹内的这几个地方：

  • data/ — 候选人、岗位、匹配等核心数据
  • vault/ — 简历原件等文件
  • config.yaml / .env — 你的专属配置
  • logs/ / runtime/ — 运行日志与临时状态
收到新版本时，别删这几个目录

以后我们发新版本给你时， data/、vault/、config.yaml、.env、logs/、runtime/ 这几个目录和文件是你的数据，不要删除。 升级步骤我们会随新版本一起说明，照着做就能保留全部数据。

常见提示

双击启动时 Windows 弹出蓝色「已保护你的电脑」

这是 Windows SmartScreen 对不常见程序的默认拦截，不是病毒。 点窗口里的「更多信息」→「仍要运行」即可。 只有第一次会拦，之后就不再提示。

浏览器打开 127.0.0.1:8000 显示「无法访问」

通常是 Hunter 还没启动完或没启动。检查：① 那个黑色命令行窗口是不是还开着； ② 是不是显示启动完成了。如果窗口已经关了，重新双击 HunterStart.exe， 等启动完再刷新页面。

改了文件夹名字后启动不了

如果你是启动过之后才改的文件夹名字或挪了位置，可能导致异常。 最稳的做法：把文件夹名字和位置改回原样再启动； 或者联系我们重新拿一份干净的包，这次在第一次启动前就把名字定好。

试用包有有效期

试用包有使用期限（具体日期见我们给你的邮件）。到期后想继续用，联系我们换新包即可， 你的数据可以保留迁移。
