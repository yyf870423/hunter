Mapping

客户突然要找「某领域的资深候选人」，最高效的路径是从对标公司的对标岗位定向联系—— 但前提是你有维护好的人才地图。Mapping 用思维导图建对标公司的组织结构， 每个节点自动关联到候选人库，你的库覆盖了对标公司多少人，一目了然。

产品里对应左侧导航「寻访（找人）」分组下的「人才地图」。

先理清几个概念

  • 地图：一个独立的人才地图，对应一个调研主题（如「AI 大模型领域人才地图」「车企智驾团队地图」）。可以建多张
  • 公司（树的根节点）：地图里的每个对标公司是一棵树，如「字节大模型团队」「阿里达摩院 NLP」
  • 节点：公司树下的任意一层，内容自由填写（常见写法如「部门 / 组 / 岗位 / 具体人名」）
  • 关联：节点上的人名如果命中候选人库里的某个人，会自动关联过去——这是 Mapping 价值的核心

人才地图列表页

打开后从上到下：

  • 搜索框：按地图名搜
  • 「+ 新建地图」按钮（蓝色主按钮）
  • 进行中的导入：如果你刚上传了脑图 / Excel 文件，会在顶部显示导入进度卡， 带进度条和状态标（处理中 / 待确认）——点卡片可进导入处理页看详细阶段
  • 地图卡片网格：每张地图一张卡，显示名称、目标公司、4 个 关键指标、创建日期。卡片可拖拽排序

每张地图卡上的 4 个 关键指标：

  • 节点：地图里所有节点的总数
  • 强关联：已经成功关联到候选人库的关联数（命中候选人的次数）
  • 未关联候选人：节点写了人名但库里没找到，提示你可以补简历
  • 待确认：系统找到候选人但不确定是否是同一人，等你确认（数字 > 0 时会有橙色警告图标）
左侧导航 →「人才地图」— 每张地图一张卡，4 关键指标（节点 / 强关联 / 未关联候选人 / 待确认）

新建一张地图

  1. 点右上角「+ 新建地图」

    弹出新建弹窗。

  2. 填地图名称（必填）

    名字要能让你未来一眼看出地图主题。如「AI 大模型领域人才地图」「2026 Q1 车企智驾团队」。

  3. 列出目标公司（可选，每行一个）

    如「微软 / 阿里巴巴 / 百度 / 字节跳动」每行一个，作为地图的初始公司树。 后续在地图内还能继续添加。

  4. 列出目标职能（可选，逗号分隔）

    如「大模型研究员、AI 算法负责人、NLP 工程师」——这是你关心的岗位，后续提取节点时会用到。

  5. 点「创建地图」

    地图建好后，回到列表页能看到这张新卡，点进去开始建结构。

进入一张地图：详情页

详情页是建图、看图、编辑的主战场。从上到下：

  • 顶部：标题 + 「重新提取」按钮 + 「导入」dropdown + 「导出」dropdown
  • 关键指标 行：节点总数 / 已关联节点 / 强关联 / 未关联候选人 / 待确认
  • 公司标签页：地图里的每个对标公司是一个标签页，「＋ 添加公司」按钮
  • 视图切换：「思维导图」/「树视图」
  • 节点搜索：在当前公司树里搜节点
  • 左侧：视图区（思维导图或树视图）
  • 右侧：节点详情面板（点击某个节点显示）

建结构：两种视图，怎么选

树视图：适合快速录入

左侧是层级缩进的树，每行 hover 时会出现「+ 子节点」按钮。 适合从零开始批量录入——你脑子里清楚组织结构，按一行接一行写下去。

思维导图：适合可视化梳理

左侧是可视化思维导图（中央根节点向外辐射），可缩放、拖动、右键菜单。 适合看图比看树更直观的场景——自己梳理整体结构、看清楚库内覆盖了哪些区块。

地图详情页 — 思维导图视图与公司标签页切换

思维导图快捷键

开启思维导图视图后，右上角「操作提示」面板列出全部快捷键：

  • Tab：新增子节点
  • Enter：新增兄弟节点（同级）
  • 双击 / F2：编辑节点
  • Backspace / Del：删除节点
  • 滚轮：缩放
  • 左键拖动：平移画布
  • 右键：更多操作菜单

连线样式可选弧形或直角（默认直角，组织树更清晰）。

两种视图实时同步

在树视图里加的节点，切到思维导图也能看到，反之亦然——这是同一份数据的两种呈现。 按场景选用哪个视图，不存在「重新做」一遍的问题。

节点自动关联候选人

这是 Mapping 和普通脑图工具的核心差异。

每次你新建或编辑一个节点（含人名），Hunter 会自动尝试关联到候选人库：

  1. 命中库内候选人 → 强关联

    节点上会显示候选人的小头像 / 标识，点节点可在右侧详情面板看到候选人完整档案。

  2. 找到候选人但不确定 → 待确认

    常见情况：节点写「张伟」，库里有 3 个张伟。 Hunter 不会乱猜，会进「待确认」队列让你自己看清楚是哪个。 列表页和详情页 关键指标 都会有橙色警告提示。

  3. 库里没找到 → 未关联

    节点有人名但库里没这个人。这是个机会信号—— 「我知道这个人在某公司某岗位，可惜库里没简历」， 意味着你可以专门去找这个人的简历，找到后入库会自动关联到 mapping。

重新提取：批量补关联

如果你新导入了一批简历到候选人库（候选人库变大了）， 想让 mapping 里原本"未关联"的节点重新尝试关联—— 点详情页顶部的「重新提取」按钮，会重新识别所有未识别的人名并尝试关联。

导入 / 导出：7 种格式互通

你过去可能用 XMind / EdrawMind / WPS / 幕布 / FreeMind 等工具画过对标公司组织图， 也可能有一份 Excel 表存着人才盘点—— Mapping 支持7 种格式互导，老资产可以直接搬进来，建好的图也可以导出做备份、离线查看或二次编辑。

7 种格式分两类：

  • 脑图 / 大纲类（5 种）：EdrawMind（.emmx）、XMind（.xmind）、 OPML（.opml）、FreeMind（.mm）、Markdown（.md）—— 导入后系统会自动识别节点里的人名并尝试关联候选人库
  • Hunter 自有结构化类（2 种）：Excel（.xlsx）、Hunter 备份（.json）—— 这两种自带候选人关联信息，导入时直接沿用，不必重新识别人名

导入到当前地图

详情页顶部「导入」dropdown，选格式：

  • .emmx：EdrawMind / WPS 思维导图原生格式
  • .xmind：XMind 软件原生格式
  • .opml：通用大纲格式（幕布 / OmniOutliner 等）
  • .mm：FreeMind / Freeplane 兼容格式
  • .md / .markdown：Markdown 大纲格式
  • .xlsx：Excel 表格——可用模板从零填，也可导出后改完再导回（见下方「Excel 导入」）
  • .json：Hunter 自己导出的备份（无损含关联信息）
导入默认「追加」，同名公司会问你「保留还是替换」

导入的公司（一级树）默认追加到当前地图，不会清空你已有的内容。 但如果导入文件里有和当前地图同名的公司，写入前会弹出确认，让你二选一：

  • 保留两个看板：当前同名 tab 保持不变，导入的同名公司自动加「（导入）」后缀，两份都在
  • 替换同名看板：删除当前地图里的同名公司及其子节点，用导入文件里的对应公司替换；不同名的公司照常追加

想彻底从零开始的话，先新建一张空地图再导入即可。

Excel 导入：先下模板，填好再导回

Excel 是最适合「先离线整理、再批量入库」的格式。选「导入 → 导入 Excel」会弹出上传框， 上面有一行「没有模板？下载 Excel 模板」——先下模板照着填，格式一定对得上。

模板是一张单表，用逐层展开的列表示组织结构，每一层一组固定列：

  • 公司 / 根节点：第 1 层，写对标公司名
  • 第 2 层节点、第 3 层节点……：往右一列深一层（部门 / 组 / 岗位等，可以一直往下加层）
  • 关联人：这一层节点上要挂的人名；同一个节点有多个人，就在一格里一行写一个
  • 关联信息：这个人的关联状态（已关联 / 待确认 / 未关联），Hunter 导出时自动填，你自己填模板可以留空
  • 备注：写在对应层的备注列，节点的补充说明

填的时候不用每一行都从第 1 层重复写公司名——上层单元格留空就表示「沿用上面那行」， 只在换公司 / 换部门时才填新值，和平时做 Excel 分组的习惯一致。

导出的 Excel 是「可回填」的

从 Mapping 导出的 Excel 里，除了你看得到的层级和人名，还藏着几列隐藏标识—— 正因如此，你可以把导出的 Excel 发出去让同事补充，回来直接导回 Mapping， 结构和已有的候选人关联都能精确还原，不会因为同名节点被搞乱。你自己新填的行和层级也能一并导入。

Excel 导入前会先校验格式

上传后系统会先检查表头和层级是否合规（比如层级列必须从左到右连续、有关联信息就必须有对应关联人）。 格式不对会直接给出具体到单元格的报错并阻断导入——照模板填一般都能过。 只支持一个有内容的工作表，多余的 sheet 要先删掉。

地图详情页「导入」下拉:emmx / XMind / OPML / FreeMind / Markdown / Excel / JSON 七种格式

导出当前地图

顶部「导出」dropdown，导出的是当前正在看的那个公司标签页（tab），7 种格式与导入一一对应：

  • .emmx：用 EdrawMind / WPS 打开
  • .xmind：用 XMind 打开
  • .opml：通用大纲格式（幕布 / OmniOutliner）
  • .mm：FreeMind / Freeplane 兼容格式
  • .md：纯文本大纲，能在任意编辑器打开、方便 diff
  • .xlsx：Excel 表格，改完能重新导回（含隐藏标识，无损还原）
  • .json：Hunter 备份格式，含候选人关联信息，迁移机器时用

导入是后台任务：看进度、必要时确认

导入不是「一点就完」，尤其是节点多、要识别人名的脑图文件——所以导入被做成后台任务： 上传后立刻给你一张进度卡，你不用干等着，可以先去做别的。处理分几个阶段推进：

  1. 解析：读文件、还原组织结构
  2. 识别人名：从节点文字里找出人名（脑图 / 大纲类格式才有这一步；Excel / json 自带关联信息，跳过）
  3. 匹配候选人：把识别出的人名和候选人库比对，判定强关联 / 待确认 / 未关联
  4. 完成：全部成功后才写入，这张地图 / 这些新节点才正式出现
要么全成功，要么全回滚

所有阶段都成功才会正式写入，中途失败会整体回滚，不会给你留一张半成品地图。 少数人名没识别出来不算失败——地图照样建好，那些节点标成「未提取」，你之后可以在节点详情页手动重新识别。

遇到同名公司时，进度会停在「待确认」：进度卡的状态标变成「待确认」， 点进去（或回到地图）选完「保留两个看板 / 替换同名看板」，任务才继续跑完。 没同名冲突就一路跑到完成，不需要你操作。

导入处理页

最佳实践

每周固定一段时间维护 mapping

建议每周抽固定一段时间更新人才地图—— 把这周新看到的人选放进合适的节点、新听到的组织调整反映在结构里。 日常工作中你接触的信息很碎，集中梳理一次比临时抓取效率高 10 倍。

未关联节点是「猎头任务清单」

列表页 关键指标 里的「未关联候选人」数字其实是你的下一步寻人清单—— 点进去看到节点上的人名你都知道在哪个公司哪个岗位，专门去找这些人的联系方式， 找到一个就把库扩充一格，mapping 的强关联数也涨一格。

常见提示

导入后节点没自动关联

常见原因：节点里的人名跟库里候选人姓名不完全一致（如库里是「Wang Xiaoming」，节点写「王晓明」）—— 自动关联要求姓名完全一致才会命中。 不一致时手动点该节点，在右侧详情面板里搜索并关联即可；也可点顶部「重新提取」再识别一次。

XMind / FreeMind 导入后视觉装饰丢了

XMind、FreeMind 里的高级元素（关系线、自由主题、边界、图标、样式等）在 Mapping 里没有对应概念，会被简化为普通子节点。 核心组织结构都能保留，但视觉装饰可能丢失，这是预期行为。

删除地图不可恢复

删除一张地图会清掉所有组织架构数据，不可恢复。 如果只是想暂时不看到，建议导出 .json 备份后再删—— 未来可以从 json 恢复（导入到新建地图）。
